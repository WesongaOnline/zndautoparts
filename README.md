# ZND Autoparts 🚗🔧

Welcome to **ZND Autoparts**, an online autoparts store designed to blend clarity, speed, and legacy.  
This project is more than just a catalogue — it’s a digital hearthstone where inventory, branding, and documentation serve both clients and future generations.

---

## 🌟 Features
- **Instant Inventory Search**: Quickly find parts using a dynamic search box.
- **WhatsApp Integration**: Each item includes a direct inquiry link for seamless client communication.
- **Symbolic Branding**: Colors and icons reflect family heritage and clarity.
- **Admin Tools**: Private gallery and interactive quizzes for client engagement.

---

## 📂 Project Structure
- `znd0.html` → Homepage with inventory table and search functionality.
- `.github/workflows` → GitHub Actions for automated greetings and CI/CD.
- `README.md` → Project overview and documentation.
